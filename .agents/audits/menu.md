## VERDICT

**FAIL — not 1:1.** The state machine, all `*Action`/`*ActionImpl` logic, the 9-zone touch grid, dialog box lifecycle, and the full `draw()` (in `menu_draw.rs`) are faithfully ported, but entire user-facing subsystems are unimplemented: the single most important gap is that **the favorites feature (F1/F2 + profile favorite data), the online dialog input flow (login/register/delete typing + sequence transitions), the mouse wheel, and profile file persistence are all missing** — a player cannot favorite levels, type into the online dialogs, navigate by wheel, or have created/deleted profiles persist.
