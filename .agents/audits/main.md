# Audit: `Core/main.cpp` ↔ `crates/oh-app` (client / compose / dispatch)

**Pair:** `src/SSVOpenHexagon/Core/main.cpp` (688 lines, read completely) ↔
`crates/oh-app/src/client.rs` (263), `crates/oh-app/src/compose.rs` (470),
`crates/oh-app/src/dispatch.rs` (437) — the three named counterparts — plus the
support modules those three delegate to, verified read-only where a claim needed
proof: `args.rs`, `lifecycle.rs`, `print_lua_docs.rs`, `steam.rs`, `main.rs`,
`windowed.rs` (3278 — the C++ windowed `mainClient` path's real home), and the
referenced C++ library pieces (`extlibs/SSVStart/include/SSVStart/GameSystem/GameWindow.hpp`,
`Timers/TimerStatic.hpp`, `GameEngine.hpp`; `Global/{Version,Imgui,Audio}.hpp/cpp`;
`Core/{HexagonClient,Replay,HexagonServer,MenuGame,Steam}.cpp`;
`Global/{Assets,Config}.cpp`; `oh-render/src/window.rs` + `gl.rs`).

**Audit focus:** the CLI, the boot order, headless/server modes, the window
setters (the `mustRecreate` family).

**Method:** full read of both sides; behavior inventory built per function;
every suspected absence grep-verified (commands + results quoted below). All
commands run from `/home/gary/dev/SSVOpenHexagon`. C++ line citations inside the
Rust comments were re-checked against the C++ files — systematic drift found
(see DIFFERENT D8).

Key C++ semantics used below: `GameWindow` setters (`setSize`/`setPixelMult`/
`setFullscreen`/`setAntialiasingLevel`/`setVsync`) only store members + set
`mustRecreate = true` (GameWindow.hpp:212-234); the physical window is created
with those values inside `recreateWindow()` (GameWindow.hpp:89-105) at the FIRST
iteration of `run()` (`if(mustRecreate) recreateWindow();`, :123) — i.e. the
C++ boot window is created with the config's fullscreen style, MSAA level,
physical size, vsync and framerate limit already in force.
